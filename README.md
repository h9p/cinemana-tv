# سينما همام

تطبيق شاشات يعرض الأفلام والمسلسلات بواجهة مصممة للتحكم بالريموت (الأسهم + OK + رجوع)، ويعمل أيضاً بالماوس واللمس، ويتكيّف مع كل أحجام الشاشات من الموبايل إلى 4K.

جميع الحقوق محفوظة للمهندس همام أبو الحسن.

## المحتويات
- `www/` — التطبيق نفسه (HTML/CSS/JS). يشتغل على أي متصفح تلفزيون أو كمبيوتر أو موبايل.
- `android/` — مشروع Android TV يغلّف التطبيق في APK (يظهر في واجهة Android TV ويتعامل مع زر الرجوع في الريموت).
- `serve.js` — سيرفر محلي صغير للتجربة.

## التجربة على الكمبيوتر
```
node serve.js 8080
```
ثم افتح `http://localhost:8080`. على أي جهاز بنفس الشبكة افتح `http://<IP الكمبيوتر>:8080`.

## بناء APK لأجهزة Android TV
**الطريقة 1 — Android Studio:** افتح مجلد `android` ثم Build ‣ Build APK(s).
الملف يطلع في `android/app/build/outputs/apk/`.

**الطريقة 2 — بدون Android Studio (GitHub):** ارفع المشروع كمستودع على GitHub،
وراح يبني `.github/workflows/build-apk.yml` الـ APK تلقائياً. حمّله من صفحة Actions ‣ Artifacts.

التثبيت على التلفزيون: انقل الـ APK بفلاشة أو بتطبيق "Send Files to TV"، أو:
```
adb connect <IP التلفزيون>
adb install CinemaHumam.apk
```

## أزرار الريموت
| الزر | الوظيفة |
|---|---|
| الأسهم | التنقل بين العناصر |
| OK | فتح / تشغيل |
| رجوع | الرجوع للصفحة السابقة (من الرئيسية: خروج) |
| في المشغّل: يمين/يسار | تقديم/ترجيع 10 ثواني (تتجمّع عند الضغط المتكرر) |
| في المشغّل: OK | إيقاف مؤقت / تشغيل (أو تخطي المقدمة إذا ظاهر) |
| في المشغّل: أعلى/أسفل | إظهار أزرار التحكم |
| أزرار الميديا (⏯ ⏩ ⏪ ⏭) | مدعومة |

## مميزات المشغّل
- اختيار الدقة (240p ← 4K) حسب الملفات المتوفرة على السيرفر، ويتذكر اختيارك.
- الترجمة (عربي / إنكليزي / إيقاف) + حجم خط الترجمة.
- سرعة التشغيل، تخطي المقدمة، الحلقة التالية وقائمة الحلقات للمسلسلات.
- يحفظ مكان التوقف ويكمل منه، وقسم "تابع المشاهدة".
- إذا فشلت دقة معينة على الجهاز (مثلاً 4K على شاشة قديمة) ينزل تلقائياً لدقة أقل.
